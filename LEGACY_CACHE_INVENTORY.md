# Legacy Cache Inventory

Run this in Colab after mounting Google Drive:

```bash
python cache_manager_v10_p4.py discover
```

The command creates the live inventory at:

```text
/content/drive/MyDrive/VisDrone_Results/ACMOT_CACHE/registry/LEGACY_CACHE_INVENTORY.md
```

and:

```text
/content/drive/MyDrive/VisDrone_Results/ACMOT_CACHE/registry/LEGACY_CACHE_INVENTORY.json
```

This repository copy is only the template. The live file must be generated from the currently authorized Drive account.
